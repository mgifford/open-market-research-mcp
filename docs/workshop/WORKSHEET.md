Use this worksheet with the fictional DITAP case. Do not enter real
procurement, vendor, or personal data.

## 1. Define the need

- Research title:
- Who must be able to use the service?
- What outcome must improve?
- What constraints or unknowns matter?
- ICT category:
- What would “success” look like for users, not for a vendor?

## 4. Evidence questions

For each option, record:

- What exact product, version, and configuration is being evaluated?
- Does the ACR match that version and scope?
- Which user tasks are affected by a partial claim or a reported barrier?
- What independent testing exists, and what did it cover?
- What is missing, and who can provide it?
- Does any possible exception need agency review? (Do not approve it here.)

## 5. Decision log

- What did we learn that changes the research plan?
- What is still unknown?
- Which source or specialist is needed next?
- What must a human reviewer check before this is used?
- What would we refuse to conclude from this evidence?
