# Pinned upstream OpenACR schema

`openacr-0.1.0.json` is copied unchanged from the GSA OpenACR project for
local import validation.

- Upstream: <https://github.com/GSA/openacr/blob/main/schema/openacr-0.1.0.json>
- Upstream commit: `86f890a07a2a193d2a9404fb57d2cc2d62a60a4f`
- Package used for validation in CI: `@openacr/openacr@0.3.8`
- Retrieved: 2026-11-12

It is used only to validate imported reports, not to generate, certify, or
publish an ACR. Upstream catalogs, templates, and the CLI remain in the
pinned npm package and are not copied here. See the upstream `LICENSE.md` for
the mixed public-domain and W3C data licensing terms. This project does not
relicense upstream material.
